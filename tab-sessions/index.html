Privacy Policy — Tab Sessions

Chrome extension · Last updated 24 September 2026

Tab Sessions has no server, no account, and makes no network requests of any kind. Everything it saves stays in Chrome's local storage on your own device. Nothing is sent anywhere, because there is nowhere for it to be sent.

What it stores

When you click Save this window or Save all windows, the extension records, for that session:

  • the URL and title of each open tab
  • whether a tab is pinned, and its position in the window
  • the title and color of each Chrome tab group
  • the name you give the session, and the time it was saved

It also keeps up to five automatic backups of that same data, so that a crash or a mistake does not lose your sessions.

Where it is stored

In chrome.storage.local — Chrome's own local storage on the device you are using. It is not synced, not uploaded, and not readable by the developer or by anyone else.

What it does not do

  • It does not transmit data anywhere. The extension declares no host permissions and contains no code that makes network requests.
  • It does not use analytics, telemetry, crash reporting or advertising.
  • It does not read the content of the pages you visit. It has no content scripts.
  • It does not require an account, an email address or a sign-in.
  • It does not sell, share or transfer data to third parties.
  • It does not use data for creditworthiness or lending purposes.
  • It does not use data for any purpose unrelated to the single purpose below.

How Chrome Web Store classifies this

Chrome Web Store requires extensions to disclose data they handle even when it never leaves the device. Under those rules, saving the addresses and titles of your tabs counts as web browsing activity, and it is disclosed on the store listing. It stays on your device.

Single purpose

To save your open Chrome windows, tabs and tab groups as named sessions and restore them later. Everything is stored locally.

Permissions, and why each is needed

PermissionWhy
tabs To read the URL, title, pinned state and order of your open tabs when you save a session, and to re-apply the pinned state when you restore one.
tabGroups To read the title and color of your tab groups when saving, and to recreate them when restoring.
storage To keep your saved sessions and their backups on your device.
unlimitedStorage So that saving many large windows never silently fails against Chrome's default storage quota.

The extension requests no host permissions, so it has no access to the websites you visit.

Export and import

You can export everything to a JSON file at any time. Chrome writes that file to a location you choose, and the extension has no further involvement with it. Importing reads a file you select and replaces your saved sessions; the state from before the import is kept as a backup.

Deleting your data

Delete individual sessions from the extension's popup, or remove the extension from Chrome to delete everything it has stored. Because no copy exists anywhere else, removing the extension removes the data.

Children

The extension is a general-purpose utility. It is not directed at children and collects no information about who is using it.

Changes to this policy

If the extension ever changes what it stores or how, this policy will be updated before that version is published, and the date above will change.
