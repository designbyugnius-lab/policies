Privacy Policy — Staymark

Chrome extension · Last updated 24 September 2026

Staymark has no server, no account, and makes no network requests of any kind. Your highlights and notes are stored in Chrome's local storage on your own device. Nothing is sent anywhere, because there is nowhere for it to be sent.

What it stores

For each page on which you make a highlight:

  • the page address, with the #fragment and common tracking parameters (utm_*, fbclid, gclid) removed
  • the page title and the time it was last changed

For each highlight:

  • the highlighted text, up to 32 characters before and after it, and a position hint — used only to find the same passage again when you come back
  • its color, the note you wrote (if any), and when it was made

It also keeps copies of that same data so that a crash or a mistake does not lose your highlights: the state before the most recent change, and up to five older copies. It remembers the color you used last.

The list of sites where you turned on automatic display is kept by Chrome itself, as a permission you granted.

Where it is stored

In chrome.storage.local — Chrome's own local storage on the device you are using. It is not synced, not uploaded, and not readable by the developer or by anyone else.

When it reads a page

To draw a highlight, and to find your highlights again, Staymark reads the text of the page in your browser. It does this only:

  • in the tab where you just used Staymark (the right-click menu, the keyboard shortcut or the toolbar icon), and
  • on sites where you chose to show highlights automatically.

From the page it keeps only the text you highlighted and the few characters around it, as listed above. It does not touch text boxes, input fields or editable areas, and does not read anything you type into a website.

What it does not do

  • It does not transmit data anywhere. It contains no code that makes network requests.
  • It does not use analytics, telemetry, crash reporting or advertising.
  • It does not record which pages you visit. Only pages on which you made a highlight are stored.
  • It does not require an account, an email address or a sign-in.
  • It does not sell, share or transfer data to third parties.
  • It does not use data for creditworthiness or lending purposes.
  • It does not use data for any purpose unrelated to the single purpose below.

How Chrome Web Store classifies this

Chrome Web Store requires extensions to disclose data they handle even when it never leaves the device. Under those rules, storing page addresses and titles counts as web browsing activity, and storing the text you highlighted counts as website content. Both are disclosed on the store listing. Both stay on your device.

Single purpose

To highlight text on web pages, add notes to highlights, and show them again when you return to the page. Everything is stored locally.

Permissions, and why each is needed

PermissionWhy
activeTab When you use Staymark from the right-click menu, the shortcut or the toolbar icon, Chrome gives it temporary access to that one tab — to draw the highlight and show your saved ones.
scripting To add Staymark's own bundled script and stylesheet to that tab, or to sites where you turned on automatic display.
storage To keep your highlights, notes and their backups on your device.
unlimitedStorage So that a large collection of highlights and backups never silently fails to save against Chrome's default quota.
contextMenus To add "Highlight with Staymark" to the right-click menu when text is selected.
Optional site access Asked for only when you choose to show highlights automatically on a site, or on all sites. You can turn it off per site in Staymark's options or in Chrome's extension settings. Without it, highlights appear when you click the Staymark icon.

Export and import

You can export everything to a JSON file at any time. Chrome writes that file to a location you choose, and the extension has no further involvement with it. Importing reads a file you select and merges it with what is already there; it never replaces your highlights.

Deleting your data

Delete individual highlights and notes from the popup, or remove the extension from Chrome to delete everything it has stored, including backups. Because no copy exists anywhere else, removing the extension removes the data.

Children

The extension is a general-purpose utility. It is not directed at children and collects no information about who is using it.
